# 지도 컴포넌트 (세션 2 · 11/04)

- 쓰는 곳: 전투 쇼츠·신작 쇼츠·롱폼 지도 위에 올리는 'ㅗ' 블록, 성 표식, 광역 → 지역 줌.
- 기준: 새 디자인을 만들지 않았습니다. sandbox `~/jupil/unit.py`·`icons/`·`anim4.py` 방식과 스킬 원문을 그대로 따랐습니다.
- 바꿀 값은 **`spec.json` 한 곳**에만 있습니다. 값마다 `status`(확정 / 기존코드 / 임시)와 `source`(근거 문구)가 붙어 있습니다.

## 파일

| 파일 | 내용 |

| `forts.py` | 성 표식 `draw_fort`: 산성 / 평지성 / 목책, 모두 96×96 |

## 근거 원문

- 블록: "넓은 직사각형 + 앞쪽 짧은 돌기(바라보는 방향)… 병종은 블록 안 작은 도트 아이콘(크림 외곽선)… 글자·범례는 쓰지 않는다"(history-battle-shorts 3절 9), 원장 C6 "'ㅗ' 블록을 포맷 공통 컴포넌트로"
- 숨은 부대: "반투명 먹색 블록 + 금색 점선 테두리"(3절 10)
- 겹침: "진영 블록을 목표 성 위에 앉히지 않는다"(3절 19), "x>900에 중요한 표식·라벨 금지"(2절)
- 줌: "광역 지도에 전장 범위 금색 박스 → 1.15초 … → 0.55초 크로스페이드"(3절 13), "같은 경위도 창 … 0.55초 지수 확대 + 줌 블러 → 0.45초 섞기"(history-longform-craft)
- 금지 글자: "JUA 폰트에 없는 기호(『』, ·, →)는 쓰지 않는다 … 금지 기호를 grep으로 검사"(2절). 시안을 만들다 실제로 '·'와 '×'가 □로 깨지는 것을 확인해 검사를 넣었습니다.

## 임시값 (사용자 확인 필요)

- **블록 등급**: 기준 M = 150×64(기존 코드). 등급별 면적은 S 0.6배 / L 1.5배 / XL 2.2배이고, 병력 경계는 5천 / 1만 5천 / 4만입니다. 스킬에는 등급 규칙이 없습니다.
- 숨은 부대의 투명도(115/255)와 점선 간격(24/14)
- 성 표식 크기 96×96, 성벽 돌색(214,204,182), 세 가지 모양의 세부
- 쇼츠 맨 아래 범례 띠 높이 130px
- 한 프레임 컷을 금지하는 배율 차이 기준 1.5배

## 확인이 필요한 충돌

1. **세력 색**
   - 전투 쇼츠 블록 색: 고구려 (150,52,40), 당 (52,56,66), 말갈 (190,104,48) — battle-shorts 3절 16
   - 원장 C4(11/04 확정): 고구려 (96,34,29), 당 (70,74,84), 말갈 (118,86,62)
   - C4는 영역 면 팔레트(channel-concept:220 '영역 면 진한 저채도')로 보고 둘을 나눠 두었습니다(`palette.unit_faction` / `territory_faction`).
2. **롱폼 성·부대 아이콘**
   - 11/04 스타일 바이블의 "성·부대 아이콘, 핀 금지"를 글자 그대로 읽어 롱폼에서는 성 표식을 막았습니다(`fort.allowed.longform=false`).
   - "아이콘은 쓰고 핀만 금지"로 읽을 여지가 있습니다. 이 규칙이 롱폼의 'ㅗ' 블록 아이콘에도 해당하는지 함께 확인이 필요합니다.
3. **궁병 아이콘**: 기존 코드에 없어서 새로 그리지 않았습니다.

## 한계

- 회전한 블록은 bbox(축에 맞춘 사각형) 면적이 각도마다 달라서, 레이아웃 JSON에 `size_class`를 넣지 않고 `size_class_nominal`·`nominal_wh`만 넣습니다.
  - 크기가 같다는 것은 `grade_dims`로 보장되고 테스트로 확인했습니다.
  - lint의 등급 크기 검사가 `nominal_wh`를 읽게 바꾸면 회전 블록도 검사할 수 있습니다.
- `zoom.py`는 경위도 → 픽셀을 창 안에서 선형으로 계산합니다. 실제 지도 투영(Map.P)과는 광역에서 오차가 생길 수 있습니다(추정). v4-S 렌더러와 연결할 때 Map.P로 바꾸면 됩니다.
