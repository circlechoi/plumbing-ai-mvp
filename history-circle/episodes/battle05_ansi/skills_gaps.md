# 새 스킬 구조 시험 — 빈틈·모호한 곳 기록 (5편 대본 작업 중)

읽은 순서: history-core → history-battle-shorts/SKILL.md → reference-upload.md → history-channel-concept/SKILL.md(2절·7-2·7-3) → decisions.yaml·rubric.md·segments.yaml. **원본 synced 스킬은 열지 않았다** — 아래 빈틈은 원본을 봐도 같은 내용이라(재구조화는 이동·보존이므로) 원본을 보지 않고 기록만 함.

## A. 규칙끼리 부딪히거나 적용 범위가 불명확한 곳 (사용자 결정 필요)
1. **훅 순서 두 개**: 원장 opening_hook(줄거리 요약 훅: 아는 이름 → 약자 → 결말 → '어떻게' 질문 → 시그니처 → 제목)과 battle-shorts 1절 '첫 3초 규칙'(결과를 뒤집는 단언을 2.5초 안에 먼저). 전투 쇼츠에서 어느 순서가 우선인지 원장에 없다. 이번 대본은 단언 먼저 → 아는 이름·약자 → 질문으로 섞음.
2. **시그니처 3초(수묵 → 먹 번짐 → 실사)**: 원장 signature_opening은 '쇼츠 3초 축약판'. 전투 쇼츠는 '그림 생성 없이 코드 렌더만'이라 실사 컷이 없다. 전투 쇼츠에 시그니처가 적용되는지 불명(1~4편 기록에도 시그니처 언급 없음 → 적용 안 함으로 추정).
3. **도트 매 편 1곳 필수**: 원장 dot_sprite는 '롱폼·쇼츠·건축' — 전투 쇼츠가 '쇼츠'에 포함되는지 불명. battle-shorts 본문에는 도트 장식 규칙이 없고 블록 안 도트 아이콘만 있다.
4. **대표 인물 vs 사료에 이름 없는 인물**: '대표 인물은 제목·첫 장면에서 빼지 않는다'와 '근대에 처음 나온 이야기' 처리 규칙이 있지만, 4편 엔딩이 이미 '양만춘'을 썼다. 후대 이름(명대 소설 출처)을 화면·내레이션에 어떻게 쓸지 규칙 없음.
5. **장면 등급제(S/A/B/C)**: core 4절 '크레딧 전 애니매틱으로 장면 등급' — 전투 쇼츠는 생성 컷이 없어 등급의 대상이 무엇인지 불명. 등급을 '시안 품질'로 쓸지 '생략'할지 규칙 필요.
6. **블록 등급 vs 병력 미상**: 원장 unit_grades는 병력 기준인데, 안시성 포위 당군·수비 고구려군 수는 사료에 없다. 병력 미상일 때 등급 고르는 규칙 없음(이번엔 '개념도'로 당 L·고구려 S 임의).

## B. 새 구조에서 길 찾기가 어려웠던 곳
7. battle-shorts 9절 체크리스트의 '(7절)' 포인터가 이제 reference-upload.md를 가리키는데 본문엔 파일명이 없다(이동 표시는 6절 끝에만). 제목 규칙을 찾으려고 파일을 따로 열어야 했다.
8. **대본 파일 형식 규약이 스킬에 없다.** lint/script_lint.py 문서 문자열에만 있다('#' 장면, '화면:'·'라벨:' 접두, '인물:' 줄). battle-shorts 6절 파이프라인에 한 줄 필요.
9. **lint 오탐**: '화면:' 줄(제작 메모)과 '라벨:' 줄(실제 화면 글자)을 같은 '화면 문자열'로 보고 금지 기호(→)를 실패 처리. 제작 메모용 접두(예: '메모:')를 따로 두거나 '화면:'을 금지 기호 검사에서 빼야 한다. 이번엔 대본에서 →를 '다음'으로 바꿔 통과.
10. 성주 같은 '얼굴 없는 인물'을 지도에 표시하는 컴포넌트가 없다(스타일 바이블 '지도에 얼굴 금지'). 5편은 크림 원 + 금색 테두리로 메모했지만 components에 없음.
11. 흙산 단면 도식(높이 경쟁)·군량 게이지 같은 전술 도식 컴포넌트는 components에 없다(3-3절 규칙만 있음). 4편 scenes.py에 게이지가 있지만 git 키트에는 아직 없음(cloudfront 반입 대기).
