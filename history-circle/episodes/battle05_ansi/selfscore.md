# 자체 채점 — 대본 관문 (golden/rubric.md 대본 항목)

| 항목 | 점수 | 이유 |
|---|---|---|
| 훅 | 1 | 첫 문장 '황제가 성 하나에 묶입니다'는 2.5초 안 결과 역설 단언이고 반전(흙산)을 숨김(G03 충족). 다만 '어떻게' 질문의 대상이 '성주'로 넓어 흥미 고리가 약할 수 있음. 숫자 대비 칩('석 달')이 화면에만 있고 말에는 '석 달'이 1장면에 없음 → 1장면 내레이션에 '석 달'을 넣을지 검토 |
| 판단 깊이 | 2 | 당 쪽: 오골성 우회를 버린 이유를 '황제 친정' 조건으로 설명(바보로 그리지 않음, G06). 고구려 쪽: 버티기 + 붕괴 순간에만 출격하는 판단. 단, 성주 판단의 이유('15만의 결말을 안다')는 [해석]이라 설명란에 표기 필요 |
| 회수 | 2 | 10장면이 4편 '상책, 버티기'를 내레이션으로 직접 잇는다(G07). 8장면 '시간 싸움'이 3장면 '안전한 길'과 이어지는지는 말로 명시하지 않음 → 편집장 지적 예상 |
| 완급 | 2 | 배경 약 26%, 절정 7장면이 가장 김(약 28초, G08) |
| 문체 | 2 | lint 실패·경고 0. '것입니다' 0회, 과거형 ㅆ 0, 인물 5명. 단 TTS 위험어는 lint가 못 잡음(아래) |

- 0점 항목 없음 → 다음 관문(외부 검수: 전투 해설가 / 한국인 내레이터) 가능. 사용자 확인 전.

## 편집장이라면 무엇을 지적할지 (G25)
1. 8장면이 '왜 철군했나'를 날씨·군량으로만 말한다. 3장면 '안전한 길 = 시간을 쓴 길'을 다시 불러 "안전한 길의 값이 여기서 돌아옵니다" 같은 연결 문장이 필요하지 않나.
2. 7장면 '당 장수는 자리를 비우고 없습니다' — 왜 비웠는지 기록이 없다(私離所部). 시청자는 '왜?'를 묻는다. [기록]에 없다고 말할지, 그대로 둘지.
3. '흙산'이 TTS에서 받침 충돌(ㄱ+ㅅ)로 끊길 위험. 대안 '흙으로 쌓은 산' 또는 '토산'. 내레이터 검수에서 확인.
4. 1장면 '이름 없는 성주'와 4편 엔딩 '양만춘'이 부딪혀 보일 수 있다. 10장면의 이름 고증 문장이 엔딩의 힘을 빼는지(정보로 끝남) 검토. 대안: 이름 고증은 설명란으로 빼고 엔딩은 '버티기' 도장으로 끝.
5. '당 태종', '당군', '당 장수' — 받아쓰기에서 '당구' 오인식 사례(4편). ev 키워드는 '태종'·'흙'으로.
6. 6장면 '50만'을 화면에만 두면 동시 동원으로 오해. 칩을 '연인원 50만'으로.
7. 고구려 쪽 블록이 7장면에야 처음 움직인다. 5장면에 성 안 고구려 블록(S 등급)을 보여 두어야 7장면 출격이 '같은 부대'로 읽힌다(블록 좌표 상수).
8. 도트 그림(매 편 1곳 필수, 원장 dot_sprite)이 대본 화면 메모에 없다 — 2장면 광역에 당 기마 도트 행렬을 넣을 자리 지정 필요.
