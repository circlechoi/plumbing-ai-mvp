## 1. 기획·대본 (10/31 사용자 피드백에서)
- **해설을 적극적으로**: 사실 나열 대본은 '밋밋하다'. 판단의 동기를 [해석]으로 세게 세우고("왜가 가장 두려워한 건 하나."), 끝에 기록에 있는 반전을 둔다(671년 당 배 47척이 와서 "싸우러 온 게 아니니, 놀라서 활 쏘지 마시오"). 반전은 기록에 있는 사건만.
- **초등학생 기준**: 처음 나오는 나라·용어는 풀어 쓴다. 사용자가 고친 문장은 그대로 살린다(바꿀 필요가 있으면 이유를 붙여 제안만).
- **건축·성 주제의 핵심 = 양식**: 창고 유무 같은 세부가 아니라 '그 나라 양식이 거기 지어졌다'가 메인. 볼 수 있는 양식 요소 3개를 이름표로(오노성: 능선의 흙 성벽 / 골짜기의 돌 성벽 / 물길(수구)). 내레이션에도 한 줄로 같은 말.
- **산을 자른 단면도는 쓰지 않는다**: '시청자에게 중요하지 않다', '조감도가 아니다'(사용자). 대신 내려다본 성 전체 그림 1장 + 이름표 3개(render.py `map` anim.json markers, `move: focus`).
- 외부 검수 리뷰어(신작 쇼츠): 첫 시청자 / 고고학자(또는 해당 분야 전문가) / 쇼츠 편집 디렉터 — 사용자가 고른 조합.
- 제목 = 화면 고정 질문, 유튜브 제목 = "화면 질문 \| 장소명"(전투 해설은 "\| 전투명").

## 2. 분량 — Harrison 낭독 속도
- 오노성 편 실측: **초당 약 5.4자**(공백 포함 대본 기준). 스킬 기준(7자 안팎)으로 잡은 대본이 60.9초가 나왔다. 45~52초 목표면 대본을 **약 260~280자**로 잡는다.
- 길이 맞추는 순서(질 손상 적은 순): ① 문장 하나 빼기(사용자와 합의, 오노성 편은 '스카우트' 문장 삭제로 약 4초) ② 문장 사이 무음을 0.35초로 고정(인용문 앞만 0.6초) ③ `atempo=1.12` 이내. 1.15를 넘기면 서두르는 느낌.
- 이어 붙이기: 부분 재녹음(문장 하나)은 원본과 같은 voice·instruction으로 받고 `atrim`으로 잘라 이어 붙인다. 백강은 '밲강'으로 쓴다.
- 장면 시작 시각 = faster-whisper 단어 타임스탬프의 그 문장 첫 단어 + 0.4초.

## 3. 화면
- 시그니처 3초판(수묵 → 먹 번짐 → 실사)은 첫 장면 아래에 깔고 제목은 0초부터(history-shorts D-1).
- 지도 장면은 전체 화면 지도 영상(history-map-v4 10절)을 `"video"`로. 그림 장면은 `move: in/out/focus`, 전환은 ink 기본 + whip/flash는 강조 때만.
- 인용문 반전은 punch 자막 두 줄(`punch: [{text, at, dur, size:100}]`)로 끊어서. 붓글씨 스타일은 다음 과제.
- 도트 스프라이트는 마지막 '오늘' 장면 하늘 위(y 약 1012) — 성벽이나 산 단면을 가로지르지 않게.
- 색: 왜 = 일장기 빨강(206,32,46), 백제 = 금색 포인트(망명 장수 옷 포함), 당 = 먹회색, 신라 = 주홍.

## 4. 썸네일 (10/31 확정 방식)
- 쇼츠 맞춤 썸네일 업로드는 2026년 7월부터 가능(보도 기준, 쇼츠는 A/B 테스트 불가). 피드에서 위아래가 잘릴 수 있으니 **문구는 화면 가운데 띠(y 600~1300)**에.
- 구성(채택 A안): 영상 속 장면 중 주제가 그림으로 읽히는 컷(성벽을 쌓는 백제인 + 금색 포인트 장수) → 가운데 띠만 위아래로 부드럽게 어둡게 → 빨간 꼬리표(장소 · 지역, 흰 글자 둥근 사각) → 큰 문구 3줄 = **영상 제목과 같은 문장**, 핵심어 하나만 금색(255,200,40), 흰 글자 검은 테두리 14px.
- 서체: 본고딕(fonts/NSK.ttf)은 가변 서체라 그냥 쓰면 Thin으로 나온다 → `f.set_variation_by_axes([900])`(꼬리표는 800).
- 우측 상단 '역사서클': 영상 워터마크와 같은 서체(fonts/X.ttf) 흰 글자 + 검은 테두리 2px, **크기 38, 불투명도 75%**, 오른쪽 끝 x 1010, y 약 90(하늘 쪽). 영상 크기 30은 썸네일에서 안 보인다.
- 코드: 키트 zip의 r/thumb.py(fit · shade · line · tag 함수). 크레딧 0.

## 6. 샌드박스 렌더 운영 (Higgsfield sandbox_exec)
- 작업공간(Bash)에서는 s3·cloudfront가 403 → 지도·렌더·업로드는 전부 sandbox에서.
- **foreground 호출은 약 60초를 넘기면 Bad Gateway(502)** → 렌더는 `nohup python3 render.py scenes.json > render.log 2>&1 &`로 띄우고 `sleep 40~45; tail -1 render.log`로 나눠 확인. 52초 영상 전체 렌더 약 5~6분.
- 미리보기: `PREVIEW=2.5,8,... python3 render.py scenes.json`(백그라운드) → 270×480 콘택트 시트로 한 번에 본다(512KiB 넘는 이미지는 안 열림).
- 업로드: media_upload → `curl -X PUT -H 'Content-Type: …' -H 'If-None-Match: *' --data-binary @파일 '<url>'` → media_confirm. **큰 파일은 첫 PUT이 400을 내는 경우가 있다 → 같은 URL로 한 번 더 PUT하면 200.**
- 편이 끝나면 키트를 zip으로 백업해 업로드하고 URL을 0절과 history-map-v4 9절에 적는다.
