## 0. 형식 (10/23 확정 — concept 12)
- **기본 = '그 시절 ○○'**: 2번 비트(개별 건축 편)로 만든다. **[10/23] 질문은 판단 언어로** — "왜 그렇게 짓기로 했을까?"(제약 → 선택 → 대가). 2번 비트의 '당신이라면?→해법'이 곧 판단 구간이다. 1편 쪽구들(0-2). 다음 편 후보는 1번 체크포인트 표로 낸다
- **보류 = '도시의 일생'**: 아래 비트·city_grow.py 명세는 재개할 때 쓴다. 졸본 단독 편은 만들지 않는다(10/17). '고구려 수도 세 번 이사' 편은 10/18 중단 → 10/23 보류. 서울은 문법이 다듬어진 뒤

### 도시의 일생 비트(보류 — v0.2 기록)
- 시리즈의 주인공은 도시다(10/17 사용자 결정). 기획은 컨셉 12-1 프롬프트(도시공학자 / 건축사학자 / 기획자)의 출력 순서를 따른다: 도시 후보 표 → 도시 연표 + 건축 카드 → 키프레임 + 대본 → 미확인·결정 사항. 기획 산출물은 Claude Docs 제작 문서로
- 쇼츠 비트(45~60초) [제안]: 시그니처 3초(도시 선묘 → 먹 → 실사 부감) → 질문 "왜 여기에?" → 블록 성장 지도가 단계별로 자람(단계마다 한 문장 + 실사 1컷 또는 그림 도해 1컷) → 발달 사유 한 문장 → 오늘 남은 흔적 + 시청자 질문
- **블록 성장 지도(city_grow.py) [미구현 — '도시의 일생' 재개 첫 편에서 작성·시안 확인 후 코드 추가]**
  - 세로 2160x3840, 한지 바탕 + 지형 음영(지도 v3 키트 tiles·style 결과를 옅게) + 강
  - 단계 spec: `{"stages":[{"year":"기원전 37","label":"…","walls":[[lon,lat],…],"blocks":{"area":[[lon,lat],…],"density":0.4},"at":0.0,"dur":3.0},…]}` — 블록은 영역 안에 난수 격자로 뿌린 작은 사각(장식, 위치 근거 없음), 새 블록은 진사 → 다음 단계에서 먹
  - 연도 카운터(아라비아 숫자, 기원전 표기), 왕조 낙관(붉은 인장 '§'), 큰 붓글씨 도시명은 렌더러 레이어로
  - 경계: 발굴·연구로 확인된 성벽은 실선, 나머지는 점선 [복원추정]
- 레퍼런스(베이징 블록 성장 타임랩스, 10/17)의 문법만 가져온다. 프레임·서체·아이콘 복제 금지

## 3. 고증
- 태그: concept 5-1 마스터 태그 표 — 이 시리즈는 [기록] [통설] [추정] [해석] [연출] [발굴] [복원추정]을 쓴다
- 출처 우선순위: 1차 사료·당대 규정문 → 건축사 학술서·논문 → 박물관·유네스코·국가유산청 등 기관 → 개설서·백과사전. 위키류는 출발점으로만. 검색 결과로 확인한 것만 단정한다
- 치수·연대 표: 항목 | 값 | 출처 | 등급. 출처끼리 다르면 범위로 말하고("약 40여 미터") 설명란에 밝힌다
- 속설(예: 정면 폭 과세 때문에 집이 좁아졌다)은 [통설·논쟁]으로 말하고 반론 한 줄
- 현대 지표(용적률·건폐율·임대수익률)를 과거에 대입하면 [추정] + 가정 치수를 설명란에
- 복원 그림의 세부(색·장식·간판·창호)는 [복원추정]. 확인되지 않은 장식을 핵심 자막으로 쓰지 않는다
- 현존 건물의 실제 사진·영상은 쓰지 않는다. 저작권이 살아 있는 현대 건축물(대략 20세기 후반 이후, 건축가 생존·사후 70년 이내)은 재현하지 않는다

## 7. 도해 (코드) [그림체 미검증 · diag.py 미구현 — 첫 편에서 작성·시안 확인 후 이 절에 코드 추가]
