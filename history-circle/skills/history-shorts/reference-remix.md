### M-2. 원본 준비
- 음악이 들어간 **최종본**을 쓴다. `ffprobe`로 크기·fps·길이를 확인한다(1부: 1920x1080, 24fps, 604.46초)
- 그림 영역과 자막 띠를 찾는다: 레터박스 안 그림 영역(1부 y 139~941, 높이 802 → `PY=139 PH=802`)과 자막이 구워진 띠(1부 y 982~1032). 그림 영역만 잘라 쓰면 롱폼 자막이 들어오지 않는다
- 컷 경계 찾기: 장면 검출(`select='gt(scene,0.3)'`, `-v error`를 붙이면 출력이 비니 빼고 stderr를 본다)이 디졸브를 놓친다 → 1초·0.25초 간격 접촉 시트로 눈으로 확인
- 자막 원문: ① 롱폼 대본 문서·p2text.json + 받아쓰기 시각(tr.json) ② sandbox faster-whisper ③ 롱폼에 구운 자막을 OCR(tesseract `kor` — traineddata는 GitHub raw의 tessdata에서 받음, 5fps로 띠를 읽고 손으로 교정). 작업공간에서는 Hugging Face 모델 받기가 403이라 10/7에는 ③을 썼다
- 글꼴(작업공간): fonts/ NSK.ttf(본고딕 가변)·SM.ttf(송명)·B.ttf·X.ttf(나눔명조, G-1 주소). ASS는 가변 서체 굵기를 고르지 못하므로 Black 인스턴스를 만든다:
  ```python
  from fontTools.ttLib import TTFont; from fontTools.varLib import instancer
  f = instancer.instantiateVariableFont(TTFont('fonts/NSK.ttf'), {'wght': 900})
  for r in f['name'].names:
      if r.nameID in (1, 4, 16): r.string = 'NSK Black'
      if r.nameID in (2, 17): r.string = 'Regular'
  f.save('fd/NSKBlack.ttf')   # fd/ = ass 필터 fontsdir: NSKBlack.ttf, SM.ttf, B.ttf, X.ttf
  ```

- **전달**: SendUserFile 한도 30MB → 넘는 편은 전달용으로 `-crf 20 -maxrate 3500k -bufsize 7000k`(오디오 copy)로 다시 인코딩해 보낸다(업로드에는 CRF 18 원본이 낫다는 것을 함께 알림)
- 10/7 오류 교훈: ① 2단 패널 높이를 홀수(835)로 두면 ffmpeg가 `malloc(): corrupted top size`로 죽는다 → 짝수 836 ② 한 입력에 trim 분기를 20개 넘게 걸면 메모리 부족으로 조용히 죽는다 → 조각마다 `-ss/-t -i`로 따로 연다(더 빠르다) ③ 금색 강조를 str.replace 연쇄로 만들면 태그가 깨진다 → 정규식 ④ 자막 끝을 늘리면 다음 자막과 겹친다
