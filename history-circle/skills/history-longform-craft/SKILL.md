이 스킬은 history-longform(v2.7, 10/25)을 보완한다. 10/28~11/04 백제 1편 〈온조〉 시안에서 편집장이 확정한 규칙·파이프라인·로그 방식을 담는다.

- 사용자 선호: 결론선행, 개조식(□/-/·), 출처, 추정·미확인 구분, 군더더기 없음. 결정은 선택지 2~4개 + 추천안. 사용자는 시안을 보고 판단하며 원하는 것을 정확히 묘사하지 못한다고 스스로 말한다 → 확정보다 함께 다듬기.

- 구도 원칙: 낮은 앵글 = 권력, 다가가기 = 긴장, 와이드 = 고립, 실루엣, 프레임 속 프레임, 일점 대칭, 3분할

| 구조 | 훅(약 40초) → 판 깔기(광역 지도 → 지역 지도 연속 줌) → 수 1~N → 판정. 예고 없음 |
| 순서 | 대본 → 녹음 → 콘티(수마다 정지 프레임 6장 승인) → 생성 → 렌더 → 자동 검수(11절) → 편집장 → 외부 검수 2인 |
| 소리 | 내레이션 빈 곳 없음. 의도한 정적은 결정적 대사 앞 1~2초만. 무음 3초 금지(제목·시그니처 포함). 구간 경계는 BGM 다리로 잇는다. BGM은 가야금 훅 트랙 하나, 전 구간 같은 믹스 기준 |
| 화면 글자 | 태그·칩·계기판 없음. 장소 설명('위치 미상')만 허용. 배역 대사는 머리말 없이 금색 따옴표 |
| 연도 표기 | 상단 띠에 '온조왕 N년 (서기 OO년/기원전 OO년)' 한 형식, kanji2.sans 34 Medium 금색(232,190,80). yearfmt.py로 자동 변환 |
| 인물 | 주인공·상대(사신)의 기준 이미지와 의상 색을 고정하고 모든 컷이 같은 기준을 참조. 같은 인물이 컷마다 달라 보이면 안 됨 |
| 지도 | 좌표는 실제 위·경도(Map.P)로만. 성·부대 아이콘, 핀 금지, 지도에 얼굴 금지. 지도 팔레트 통일 |
| 화면 지속 | 같은 지도 화면은 8초 안에 확대·이동하거나 다른 컷으로 전환. 클라이맥스는 실사 컷 30초당 1개 이상(기존 실사 재사용 가능) |
| 실사 | Kling 시작·끝 프레임을 비슷하게, 쓸 구간만 잘라 사용. 움직임 없는 스틸 2초 이상 금지. 같은 인물 반응은 한 컷 |
| 회수 | 훅 장면을 본편에서 다시 다룰 땐 같은 영상을 흑백 회상으로 재사용하고, 대사를 다시 읽지 않는다 |
| 대사·해석 | 해석 표현 3단계: '기록은 ~' / '~로 보입니다' / '~라고 보는 게 자연스럽습니다'. 연출 대사는 원문 뜻을 벗어나지 않게(편집장이 정하면 그 결정 우선) |
| 제목 카드 | 정지 카드 금지. 마지막 실사 컷을 흐리게 깔고 제목이 떠오르는 2~3초 |

## 11. 자동 검수·후처리 도구 (sandbox ~/tools, 키트에 포함)
- qa.py 영상 [--asr] [소스.py…] (현행: `lint/run_all.py <폴더> --format longform [--asr]`가 qa.py 항목을 흡수, 11/05): 길이, 3초+ 정지 화면, 6초+ 같은 화면, 검은 화면, 컷/튐, 2.5초+ 소리 빈 구간, 남은 태그(소스 grep), 발음 의심(음성 인식). 편집장에게 보여 주기 전에 매번 돌린다
  - 음성 인식은 '낙랑'을 거의 항상 '낭낭'으로 받아 적는다(인식 쪽 버릇으로 추정). 그 단어는 사람이 직접 들어 판단
  - 천천히 확대(liven)한 구간도 프레임 차이가 작아 '정지'로 잡힌다. 수치만 보지 말고 시트로 확인
- liven.py 입력 출력: 같은 화면이 1초 넘게 멈추면 그림 띠만 8초에 약 6%(최대 12%) 확대, 컷에서 초기화. 자막·상단 띠는 그대로
- assemble.py out seg… ('bed:' 접두 = 그 구간에 BGM을 낮게 깔고 내레이션에 맞춰 누름): 이어 붙인 뒤 2초+ 무음을 BGM 다리로 메움(그 이하는 의도한 정적으로 둠)
- postfix.py: 렌더 결과에 그림 띠만 바꿔 끼우기(다른 구간 실사 삽입·흑백 회상), 상단 띠 다시 쓰기
- vio.py: 1920×1080 24fps 프레임 스트리밍 입출력
- yearfmt.py: '온조왕 N년' ↔ 서기/기원전 환산(N≤18 → 기원전 19−N년, N≥19 → 서기 N−18년)
