### 도시의 일생 비트(보류 — v0.2 기록)
- 시리즈의 주인공은 도시다(10/17 사용자 결정). 기획은 컨셉 12-1 프롬프트(도시공학자 / 건축사학자 / 기획자)의 출력 순서를 따른다: 도시 후보 표 → 도시 연표 + 건축 카드 → 키프레임 + 대본 → 미확인·결정 사항. 기획 산출물은 Claude Docs 제작 문서로
- 쇼츠 비트(45~60초) [제안]: 시그니처 3초(도시 선묘 → 먹 → 실사 부감) → 질문 "왜 여기에?" → 블록 성장 지도가 단계별로 자람(단계마다 한 문장 + 실사 1컷 또는 그림 도해 1컷) → 발달 사유 한 문장 → 오늘 남은 흔적 + 시청자 질문
- **블록 성장 지도(city_grow.py) [미구현 — '도시의 일생' 재개 첫 편에서 작성·시안 확인 후 코드 추가]**
  - 세로 2160x3840, 한지 바탕 + 지형 음영(지도 v3 키트 tiles·style 결과를 옅게) + 강
  - 단계 spec: `{"stages":[{"year":"기원전 37","label":"…","walls":[[lon,lat],…],"blocks":{"area":[[lon,lat],…],"density":0.4},"at":0.0,"dur":3.0},…]}` — 블록은 영역 안에 난수 격자로 뿌린 작은 사각(장식, 위치 근거 없음), 새 블록은 진사 → 다음 단계에서 먹
  - 연도 카운터(아라비아 숫자, 기원전 표기), 왕조 낙관(붉은 인장 '§'), 큰 붓글씨 도시명은 렌더러 레이어로
  - 경계: 발굴·연구로 확인된 성벽은 실선, 나머지는 점선 [복원추정]
- 레퍼런스(베이징 블록 성장 타임랩스, 10/17)의 문법만 가져온다. 프레임·서체·아이콘 복제 금지
