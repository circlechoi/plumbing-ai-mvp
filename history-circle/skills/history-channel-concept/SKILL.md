# 역사서클 채널 컨셉 (v1.3 · 2026-10-25 · 오프닝 = 줄거리 요약 훅(7-2) · 차차 확정 중)

이 문서는 채널의 기본 틀이다. 제작 방법(생성·렌더·음악)은 `history-longform`, `history-shorts`, `history-architecture-shorts`(건축·도시 시리즈)에 있고, 
> **충돌 규칙(11/04 개편 — history-core)**: 현행 값은 원장(decisions.yaml) 하나뿐이다. 이 스킬 본문과 원장이 다르면 원장을 따른다. 원장에 없는 항목끼리 부딪히면 기존 '날짜가 붙은 최신 사용자 결정' 원칙을 따른다(원문은 archive.md '교체 원문').
항목마다 [확정](사용자가 정함) / [제안](Claude가 낸 안, 아직 미확정)을 표시한다. [제안]을 확정된 것처럼 적용하지 말고, 해당 결정이 필요한 시점에 선택지 2~4개 + 추천안으로 묻는다. 확정되면 이 문서의 표시를 바꾼다.

## 0. 작업 관점 — 역할 프롬프트 [확정 10/10 · 관문 10/23]
- [확정 10/23] **롱폼은 3단계 관문**으로 만든다: ① 비트시트 → ② 대본 → ③ 스토리보드. 관문마다 독립 리뷰어 2명(첫 시청자 / 유튜브 디렉터)이 따로 검토하고, 사용자가 편집장으로 고치고 승인한다(대본·스토리보드는 사용자가 직접 고친다). 사학자 리뷰어는 두지 않는다 — 고증은 지키되 영상이 딱딱한 강의가 되는 것을 가장 경계하기 때문. 절차는 history-longform B-0
- 아래 두 역할(기획자·디자이너)은 관문 사이에서 Claude가 작업할 때의 관점이다. 쇼츠는 각 스킬의 체크포인트를 그대로 쓴다

기획·대본·지도·컷 작업을 할 때 Claude는 아래 두 역할로 차례로 검토하고, 보고할 때 두 역할의 이름으로 나눠 적는다(예: □ 기획자 의견 / □ 디자이너 의견).
두 역할의 의견이 부딪히면 한쪽을 버리지 않는다(1번: 내용과 영상미를 같이 잡는다). 두 안을 나란히 보이고 추천안 1개와 근거 1줄을 붙여 사용자가 고르게 한다.

```
[역할 1 · 유튜브 기획자]
너는 역사/전략 시네마틱 채널 '역사서클'의 기획자다. 채널의 질문은 "그 판단은 왜 그랬을까?"이다.
할 일:
1. 세 겹 질문을 세운다(2-1) — 세계: 왜 그때 전쟁이 났나(국제 정세, 1~2분) / 나라: 왜 그 선택을 했나(전략) / 전장: 왜 그 수였나(전술).
   레퍼런스 영상은 첫 겹(국제 정세 → 전쟁 원인)까지 잘 설명한다. 우리는 마지막 겹에서 한 발 더 들어가 전술의 함의와 "왜?"에 답한다.
2. 한 편의 결정 하나를 한 문장으로 쓰고 편 구성 공식(딜레마 → 당신이라면? → 실제 선택 → 결과 → 판단 분석 → 다음 편 씨앗)에 놓는다.
3. 상대의 계산을 먼저 그럴 만하게 세우고, 승자가 그 상황과 심리를 어떻게 역이용했는지로 답한다(5번).
4. 기록이 짧으면 역사적 상상력으로 판단을 세운다(5-1). [기록]·[통설]·[해석]·[상상]을 구분하고, 상상은 그렇다고 밝힌다.
5. 시청 유지: 첫 장면은 줄거리 요약 훅(7-2, 10/25 — 배경지식 0 시청자도 '누가 무엇이 되나'를 알게), 첫 30초 안에 질문을 던진다. 구간이 바뀔 때마다 길 안내 한 문장. 끝에 다음 편으로 이어지는 조건이나 한계 한 줄.
6. 판단 분석 구간(2-2)은 사용자가 초고를 쓴다. 기획자는 빈 5칸 양식과 근거 자료를 먼저 건네고, 초안을 대신 쓰지 않는다.
산출: 세 겹 질문 표 / 구간별 핵심 문장 / 질문형 제목 후보 3개 / 라디오 시험 결과(3번).
하지 않는 것: 사건을 나열한 뒤 의미를 덧붙이는 강의식 구성, 승자 미화, 상상을 기록처럼 말하기.

[역할 2 · 영상 디자이너]
너는 같은 채널의 영상 디자이너다. 모든 컷은 ① 판단의 근거를 보여 주거나 ② 판단의 무게를 느끼게 해야 한다. 둘 다 아니면 뺀다.
할 일:
1. 지도를 세 단계 줌으로 설계한다(7-1) — 전략도(국제 정세) → 작전도(진군로·거리) → 전술도(전장). 단계 사이는 같은 바탕 위 줌인으로 이어 시청자가 길을 잃지 않게 한다.
2. 지도 문법(7-1)을 지킨다: 세력 = 진한 단색 면(지형 국경), 거점 = 흰 사각, 방어선 = 캡슐 띠, 군대 = 도트 기마병 스프라이트(10/16, 글자 토큰 대신), 이동 = 붓 화살표, 교역·보급로 = 점선.
3. 실사 컷은 작은 움직임 위주(깃발, 연기, 호흡, 시선). 원경은 회화처럼, 근경은 참혹하게. 세력 색을 모든 컷에서 지킨다(4·7번).
4. 상상 구간은 화면에서도 구분한다(5-1: 개념도 표기, 재현 컷 톤 등).
5. 화면에 적힌 모든 글자가 내레이션에도 나오는지 확인한다(3번 라디오 기준).
6. 매 편 첫머리는 콜드 오픈 → 시그니처 오프닝(7-2) 틀을 지킨다.
7. 매 편 도트 그림을 한 곳 이상 넣는다(7-3).
산출: 컷 리스트(시간 · 화면 · 컷이 하는 일 · 대응 내레이션) / 지도 레이어 명세(렌더러 layers json 초안) / 생성 프롬프트.
하지 않는 것: 글자가 들어간 깃발, 레퍼런스 영상 화면의 복제, 화면에만 있는 정보.
```
- Claude는 움직임과 소리를 직접 보거나 듣지 못한다. 디자이너 역할의 영상 판단은 정지 프레임 기준이며, 최종 판단은 사용자가 한다는 것을 보고에 밝힌다
- [확정 10/17] **건축·도시 시리즈('도시의 일생')는 12-1 프롬프트의 세 역할(도시공학자 / 건축사학자 / 유튜브 기획자 겸 영상 디자이너)로 검토한다** — 12-1

## 1. 정체성
- [확정] 한 문장: **"그 판단은 왜 그랬을까?"**
- [확정] 장르: **역사/전략 시네마틱 영상**. 특정 역사·전투에서의 판단과 그 함의를 설명하고, 그것을 영상으로 보여 준다
- [확정] 조회수 성공보다 정체성이 먼저다. 만드는 사람이 즐길 수 있어야 한다
- [확정 10/7] **내용의 구성과 영상미를 같이 잡는다.** 이것이 사용자가 재미있어하는 방향이다. 둘 중 하나를 위해 다른 하나를 버리지 않는다
- [확정 10/7] **전투 구간은 영상미를 위해 충분히 둔다.** 없애거나 내레이션으로 덮어 버리지 않는다(4번)
- [확정] **듣기만 해도 이해되는 영상**: 라디오처럼 틀어만 둔 사람도 끝까지 들으면 이해할 수 있어야 한다. 지도와 화면은 이해를 더 풍성하게 하는 것이고, 내용 자체는 소리만으로 알차야 한다(3번)
- [확정 10/9] **상대를 바보로 그리지 않는다.** 승자의 우위는 상대의 실수가 아니라, 상대의 상황과 심리를 역이용한 뛰어난 모습으로 보여 준다(5번)
- [확정 10/10] **국제 정세로 전쟁의 이유를 풀고, 한 발 더 들어가 이 전투의 전술적 함의와 "왜?"에 답한다**(2-1)
- [확정 10/10] **기록이 한 줄이어도 역사적 상상력으로 해석한다.** 사용자가 매우 중요하게 여기는 원칙이다. 짧은 기록을 발판으로 조건을 재구성하고 판단을 세우되, 상상임을 밝힌다(5-1)
- [확정 10/12] **수묵화에서 시작한 채널**: 매 편 시그니처 오프닝(수묵화 → 먹 번짐 → 실사)으로 이 정체성을 새긴다(7-2)
- [확정 10/17] **매 편 도트 그림을 하나 이상 넣는다.** 롱폼·쇼츠·건축 시리즈 모두. 깨알 등장으로 채널의 숨은 서명처럼 쓴다(7-3)
- [확정 10/17] **건축·도시 시리즈 = 도시의 일생**: "그 도시는 왜 그 자리에서, 그 모양으로 자랐고, 그 시대 건물은 왜 그렇게 생겼을까?" 1편은 「고구려 수도는 왜 세 번 이사했나」, 서울은 뒤로(12번)
- [확정 10/14] **판단을 따지는 목소리는 사용자의 것이다.** 매 편 판단 분석 구간(2-2)의 초고를 사용자가 쓴다
- [확정 10/23] **타깃 시청자**: 핵심층 = 45~64세 한국 남성 역사 애호가(10/23 기준 시청자의 84%, 남성 89%, 모바일 87%) / 확장 = 30~40대(롱폼 패키징 3안 중 1안으로 상시 시험) / 해외 = 보류(자동 더빙 한국어→영어는 가능 — 국내 재방문 시청층이 생긴 뒤 다시 검토). 도트·자막 크기·말투·썸네일을 판단할 때 이 정의를 잣대로 쓴다
- 무엇이 아닌가: 역사 다큐(사건 전체를 균형 있게 기록) / 역사 소개(인물·사건 요약) / 대하사극(긴 대화와 연기로 끌고 가는 드라마). 이 셋은 해설을 전달하는 수단으로만 빌려 쓴다
- 화면의 두 가지 일: ① 판단의 근거를 보여 준다(지도, 지형, 배치) ② 그 판단의 무게를 느끼게 한다(전투의 아름다움과 참혹함). ②도 이 채널의 본업이다

## 2. 편 구성 공식 — 결정 해설
- [확정 10/7] **한 편 = 결정 하나 = 질문 하나, 답 하나**
- [확정 10/25] **편의 첫 화면 = 줄거리 요약 훅**(7-2): 아는 이름 → 약자의 출발 → 결말 한 문장 → '어떻게' 질문 → 시그니처 → 제목. 10/23 실험 E2(질문 먼저 → 시그니처 3초 → 제목)는 이것으로 대체. 아래 10/17안은 보류(전투 컷 플래시는 결말 문장의 화면으로 흡수)
- [보류 · 10/17] **편의 첫 화면 순서**: 전투 컷 빠른 플래시(0~6초, 8~12컷, 점점 빠르게) → 정적 약 1초 → 핵심 질문 한 문장 → 먹 번짐 시그니처(7-2) → 제목. 구현은 history-longform E-4. (10/12 역순 훅 '클라이맥스 10초 → 먹 되감기 → 시그니처 → 질문 → 제목'은 2·3부 방식 — 기록용)
- [확정 10/7] 순서와 각 단계에서 **말로** 해야 하는 것:
  - ① 딜레마: 누가, 언제, 어디서, 무엇을 정해야 하는가. 제약(병력, 지형, 시간, 상대)을 말로 다 푼다. **왜 그 시기인지**도 여기서 푼다(2-1의 세계 겹)
  - ② "당신이라면?": 선택지를 소리 내어 하나씩 센다("길은 셋이었습니다. 첫째…"). **[확정 10/12] 선택지마다 한 줄**(이득·위험을 한 문장에 압축). 길게 늘이면 늘어진다는 피드백
  - ③ 실제 선택: 무엇을 골랐는지, 왜 그것이었는지. **[확정 10/12] ②와 ③은 한 구간으로 붙인다**(선택지 셈 직후 바로 선택). 이유는 **둘 이내**로 좁힌다(2부: 왕 한 사람 · 때)
  - ④ 결과: 어떻게 풀렸는지를 순서대로. **상대의 판단을 먼저 그럴 만하게 보여 주고**, 그 판단이 어떻게 역이용됐는지를 보여 준다(5번). 전투는 **말로 예고 → 영상미 구간 → 말로 정리**의 묶음으로 짠다(4번)
  - ⑤ 판단 분석: **[확정 10/14]** 그 선택을 심의 메모 틀(목표 / 제약 / 선택지 / 리스크 / 대가)로 따져 보는 1~2분 구간. 초고는 사용자가 쓴다(2-2)
  - ⑥ 다음 편의 씨앗: 이번 승리 조건이 다음 편에는 없다는 대비 → 질문
- 피할 순서: 사건 → 결과 → "이 전투의 의미는…". 이야기를 다 보여 준 뒤 함의를 강의처럼 덧붙이면 재미가 없다. 답을 알려 주기 전에 시청자를 결정하는 자리에 앉힌다. ⑤ 판단 분석은 '의미 설명'이 아니라 **평가 질문**으로 연다("그렇다면 이 선택은, 남는 장사였을까요.") — 2-2
- 전술 장면에 들어가기 전에 **전략의 이유를 먼저** 설명한다. 예: 2부는 "왕은 왜 안장을 풀었나" 이전에 "약한 나라가 왜 먼저 쳤나"가 오른다(10/8 사용자 지적)
- 통한 사례: 1부 작전 회의(성에서 버틸까 / 벌판에서 맞설까 / 고개에서 칠까), 1부 복기 구간(위기를 먼저 던지고 세 가지 이유로 답함), 1부 엔딩 질문("숨을 산도, 좁은 길도 없는 그곳에서, 작은 나라는 과연, 어떻게 싸워야 할까요."), 2부 v3 구성(콜드 오픈 → 선택지 한 줄씩 → 이유 둘 → 영상미 구간 셋)

### 2-1. 세 겹 질문 [확정 10/10]
- 한 편은 넓은 데서 좁은 데로 세 겹을 내려간다. 각 겹은 지도 줌 단계(7-1)와 짝을 이룬다

| 겹 | 질문 | 다루는 것 | 지도 |
|---|---|---|---|
| 세계 | 왜 그때 전쟁이 났나 | 주변 강국의 사정, 힘의 공백, 동맹·적대, 교역로 | 전략도 |
| 나라 | 왜 그 선택을 했나 | 국력 차이, 내부 사정, 목표(영토·생존·왕권), 대안들 | 작전도 |
| 전장 | 왜 그 수였나 | 지형, 계절, 병력 배치, 상대의 심리, 전술의 함의 | 전술도 |

- [확정 10/10] 비중: **세계 겹(국제 정세)은 1~2분 안에 자연스럽게 마무리한다.** 깊이는 전장 겹에 쓴다(채널의 차별점). 레퍼런스 영상(11번)은 세계 겹을 잘 설명한다. 우리는 전장 겹에서 "왜?"를 끝까지 판다
- 전장 겹의 "왜?"는 세 가지 답을 갖춘다: ① 그 수가 무엇을 노렸나 ② 상대는 왜 그 수에 걸렸나(상대의 합리성) ③ 그 수가 다음에 무엇을 남겼나(함의·한계)
- 세계 겹의 사실은 연대를 반드시 대조한다. 국제 정세는 인과를 단정하기 쉬운 영역이다 — "그래서 쳤다"가 아니라 "그 틈이 열려 있었다" 수준으로 말하고, 인과는 [해석]으로 표시한다
- 시즌 안에서는 앞 편의 세계 겹을 이어 쓴다(8-1). 같은 전략도 바탕을 재사용하고 바뀐 점만 보여 준다
- 예(2부): 세계 — 왕망의 신(新) 말기 중원이 흔들리던 시기(병력 징발·'하구려' 개칭 → 적미의 난) / 나라 — 약한 고구려가 왜 먼저 부여를 쳤나 / 전장 — 왕을 먼저 치면 부족 연합이 풀린다는 판단, 진창과 마른 땅

### 2-2. 판단 분석 구간 [확정 10/14 · 화면 확정 10/17(먹 글씨) · 길이는 3부 시청 지속률 확인 후]
배경(10/14): 사용자가 지금 영상에 약 70점 만족. 진단 — 정체성은 '판단 해설'인데 영상 안에서 판단을 따지는 분량이 이유 둘·한계 한 줄 수준이고, 해석의 뼈대가 강의에 기대 있어 사용자의 관점이 보이지 않는다. 사용자 결정: 판단 분석을 공식 구간으로 두고, 그 초고는 사용자가 쓴다.
- **위치**: ④ 결과 뒤, ⑥ 다음 편 씨앗 앞. **1~2분**(내레이션 약 400~800자, Harrison 초당 약 7자 기준 추정)
- **여는 문장 = 평가 질문**: 예 "그렇다면 이 선택은, 남는 장사였을까요." 다음 문장에서 경계를 밝힌다: "여기서부터는 기록이 아니라, 그날의 조건으로 따져 본 해석입니다."
- **틀(투자심의 메모식 5칸)**:
  1. 목표 — 이 결정으로 얻으려던 것 **하나**
  2. 제약 — 병력·지형·시간·상대·정세 중 결정적인 것 2~3개
  3. 선택지 — 실제로 가능했던 길(①②에서 센 것을 다시 한 줄씩)
  4. 리스크 — 길마다 무엇을 걸었나, 최악의 경우는 무엇이었나
  5. 대가 — 고른 길이 얻은 것과 치른 값, 그리고 남긴 숙제(다음 편으로 이어짐)
- **판정은 한 문장으로 낸다**: "남는 장사였다 / 비싼 승리였다 / 아직 판단할 수 없다" 중 하나 + 이유. 반대 판정의 근거도 한 문장 또는 설명란
- **태그**: 이 구간은 [해석]·[상상] 중심. 내레이터가 판단을 **평가해도 된다** — 이 구간에서는 history-longform C의 '내레이터 [해석]은 전술 원리 설명까지' 제한보다 이 규칙이 우선한다. 단 ① 기록처럼 단정하지 않는다 ② 병력·숫자를 지어내지 않는다 ③ 출발점이 되는 기록 한 줄을 대본 태그 열에 적는다(5-1)
- **라디오 기준(3번) 그대로**: 5칸을 소리로 센다("목표는 하나였습니다." → "걸린 것은 둘이었습니다."). 화면 표는 보강일 뿐
- **화면(10/17)**: 어둡게 낮춘 지도 또는 한지 화면 위에, 핵심어(목표·제약·선택·대가)가 내레이션에 맞춰 붓글씨로 한 획씩 써진다. 판정 한 단어에만 붉은 낙관. 붉은 상자·검은 띠 라벨 금지(history-longform E-7). 지도와 실사를 번갈아 쓰고 한 장면 6초 이하(E-6). 이미 본 전투 컷 재사용 금지. 조용하고 정돈된 해설 구간(4번 완급)
- **목소리 = 사용자(10/23 실험 E5, 온조 편)**: 이 구간은 Harrison 대신 사용자가 직접 녹음한다(폰 녹음 가능, 약 10분). 정체성 '판단을 따지는 목소리는 사용자의 것'을 소리로 구현한다. 그 구간의 지속 그래프와 댓글 반응으로 고정 여부를 정한다. 녹음본은 −17 LUFS로 맞추고 잡음만 걷는다(목소리 성질은 바꾸지 않는다)
- **저자 = 사용자**:
  1. Claude가 먼저 **빈 5칸 양식 + 근거 자료**(해당 기록 원문·강의 논리·지도상 조건·상대의 계산)를 건넨다. Claude가 초안을 먼저 쓰지 않는다(사용자가 요청할 때만)
  2. 사용자가 개조식 메모든 문장이든 초고를 쓴다
  3. Claude는 **고증(등급 태그)·라디오 기준·D-1 문체·길이만** 다듬는다. 사용자의 관점·판정·비유는 바꾸지 않는다. 바꿀 필요가 있으면 이유를 붙여 제안만 하고, 고친 곳마다 이유 한 줄(history-shorts B의 '사용자 문장 살리기'와 같은 방식)
- **재편집 쇼츠**: [제안] 롱폼마다 이 구간을 중심으로 한 편을 자른다(질문형 제목: "왕을 죽이고도 진 싸움이었다고?")
- **검증**: 업로드 뒤 이 구간의 시청 지속률을 따로 본다. 이탈이 크면 길이·위치를 고친다(형식 확정은 그 뒤)

## 3. 듣기만 해도 이해되게 만드는 규칙 (라디오 기준)
- [확정 10/7] 원칙: **화면에만 있는 정보는 없다.** 자막, 지도 표시, 카드, 인장에 적힌 것은 모두 소리로도 나온다. 이 원칙은 '정보'에 대한 것이지 말이 쉬지 않아야 한다는 뜻이 아니다
- [제안] 세부 규칙:
  - **말로 그리는 지도**: 지형을 방향과 비유로 푼다("국내성은 세 면이 산이고 남쪽은 강입니다. 북쪽에서 오는 군대는 고개 하나를 넘어야만 들어옵니다"). "여기", "이쪽", "보시는 것처럼"은 쓰지 않는다
  - **해설 구간에서는 말이 길게 비지 않는다**: 딜레마·선택지·선택·판단 분석 구간은 목소리 없는 시간을 짧게. **영상미 구간은 예외**(4번)
  - **대사는 전부 소리로**: 자막으로만 나가는 대사를 두지 않는다. 누가 말하는지는 목소리 차이나 내레이션으로 알 수 있게 한다
  - **길 안내**: 구간이 바뀔 때 지금 어디인지 한 문장("이제 싸울 곳을 정했으니, 남은 것은 어떻게 숨느냐였습니다"). 셈을 예고하고 센다
  - **이름과 숫자는 줄이고 되풀이**: 한 편에 기억할 이름은 적게, 다시 나올 때는 관계를 붙인다("부여의 왕 대소")
  - **지도 줌을 말로도 옮긴다**: 전략도에서 전술도로 들어갈 때 "이제 눈을 그 벌판 한 곳으로 좁혀 보겠습니다"처럼 범위가 바뀐다는 것을 말한다
  - **가닥을 바꿀 때 길 안내**: 다른 나라 가닥으로 넘어갈 때 "같은 시기, 한강 남쪽에서는"처럼 시간·장소를 먼저 말하고, 전략도 한 장으로 두 나라의 위치를 다시 보여 준다(8-1)
  - **라디오 시험**: 대본을 화면 설명 없이 글로만 다시 읽어 딜레마·선택지·선택·결과·판단 분석이 빠짐없이 이해되는지 확인한다. 녹음 전에 한다. 영상미 구간은 "(음악)" 또는 "(현장음)"으로 표시하고, 그 앞뒤 문장만으로 무슨 일이 있었는지 알 수 있는지 본다

## 4. 영상미 구간 (전투) — 내용과 영상미를 같이 잡는 방법
- [확정 10/7] 전투 구간은 충분히 두고, 영상미를 살린다
- [제안] **말로 예고 → 영상미 구간 → 말로 정리**: 전투 장면에 들어가기 전에 내레이션이 이제 무슨 일이 벌어질지를 말한다 → 화면과 소리가 끌고 간다(내레이션 없음 또는 최소) → 끝나면 무슨 일이 있었는지 한두 문장으로 정리한다. 이렇게 하면 듣기만 하는 사람은 간주로 받아들이고 내용을 놓치지 않는다
- [제안] 영상미 구간 하나의 길이와 횟수는 2부 시안을 듣고 정한다(출발점: 한 덩어리 30~45초, 편당 2~4곳. 2부 v3는 북진·진창·돌격 세 곳)
- [확정 10/12] **시각·청각의 대비(완급)**: 해설 구간(지도·회의)은 조용하고 정돈되게, 몰입 구간(행군·진창·돌격)은 현장음(발굽·진흙·숨소리·함성·바람)을 앞에 둔다. 효과음은 Higgsfield로 생성(history-longform F). 실제 밸런스는 사용자가 듣고 판단
- [확정 10/7~8] 1부 전투는 처음이라 어색한 부분과 미학적으로 부족한 부분이 있다(사용자 평가). 2부부터 정지 이미지 콘티에서 구도와 순서를 먼저 잡아 개선한다
- 참고로 삼는 연출(사용자가 10/7에 레퍼런스로 준 구로사와 아키라 〈란〉(1985) 소개 글에서):
  - **색으로 세력을 읽게 한다** — 군대마다 색을 정하면 색만으로 충돌이 읽힌다. 고구려 붉은색 대 부여 흰색·검은색. 모든 전투 컷에서 지킨다(7번)
  - **멀리서는 그림처럼, 가까이서는 참혹하게** — 원경은 정교하게 배열된 회화처럼 구도를 잡고, 근경에서 그 안의 실상을 보여 준다(피 수위는 history-longform B의 기준 유지)
  - **절정에서는 현장음을 걷어 내고 음악을 앞에 둔다** — 전투가 거대한 장송곡처럼 느껴지게. 영상미 구간의 기본 음향 설계로 시험해 본다(음악을 깔 때 사용자가 결정)
  - **그림 콘티를 먼저** — 영상으로 넘어가기 전에 정지 이미지로 전투의 구도와 순서를 다 잡는다(우리의 정지 이미지 가편집본 단계)
  - 아름다운 화면을 따라가다 보면 그 안의 잔혹함과 마주하게 되는 것 — 판단의 무게를 느끼게 하는 방식
- 참고(10/10 사용자 레퍼런스, 오장원 전투 영상 스틸): 역광·옅은 안개·저채도 청회색, 앞쪽 깃발 하나와 뒤로 넓은 진영을 둔 깊은 구도, 큰 동작 없이 깃발·연기·인물의 작은 움직임. → 정지 그림을 시작 프레임으로 만든 뒤 영상 모델로 작은 움직임만 입힌다(2부에서 Kling 3.0 pro로 적용)
- 그대로 따라 하지 않는 것: 특정 영화·영상의 장면·구도·의상을 복제하지 않는다. 원리만 가져온다

## 5. 해석 원칙
- [확정 10/9] **상대는 합리적이다. 승리는 그 합리성을 역이용한 데서 나온다.** 진 쪽을 "바보여서 당했다"로 그리지 않는다. 상대의 계산을 먼저 그럴 만하게 보여 주고, 이긴 쪽이 그 계산과 상황·심리를 어떻게 읽고 이용했는지를 보여 준다
  - 예(2부): 부여는 그 벌판이 진창인 줄 알았다. 해빙기 진창은 발목·무릎을 붙잡는 땅이라 건너지 못할 땅은 아니라고 보았을 것이다. 고구려는 어느 길로 와도 진창을 건너야 하는 자리를 골랐다
  - 예(1부): 부여는 학반령이 좁다는 것을 알고도 들어왔다. 땅을 아는 것과 그 땅을 피할 수 있는 것은 다르다
- [확정 10/8] **신이한 기사는 현대식으로 재해석한다.** 내레이션은 "기록은 이렇게 전합니다" → "오늘의 눈으로 읽으면" 두 단계로 말해 기록과 해석이 섞이지 않게 한다. 가능하면 그 기사가 이야기 안에서 하는 일(예: 원정의 약점인 군량·무기·길을 메움)로 묶는다. 길어지면 압축한다(2부 v3: 한 문단)
- [확정 10/8] **기록이 이유를 말하지 않으면** 기록의 앞뒤 순서와 해석으로 세운다. 해석·추정·추측을 대본과 설명란에 구분해 적는다
- [확정 10/10] **국제 정세는 '틈'으로 말한다.** 주변 정세가 전쟁을 일으켰다고 단정하지 않는다. 그 정세가 어떤 기회나 압박을 만들었는지까지 말하고, 그 틈을 왜 그 방식으로 이용했는지는 나라·전장 겹에서 답한다
- [제안] 추측(예: "부여 안의 반대 세력이 호응했다")은 단정하지 않고 질문으로 던지며, 뒷받침하는 기록이 나오는 대목에서 회수한다

### 5-1. 역사적 상상력 — 한 줄의 기록에서 판단을 세우는 법 [원칙 확정 10/10, 절차는 제안]
- [확정 10/10] 기록이 짧다는 이유로 주제를 버리지 않는다. 사용자와 Claude가 한 줄의 기록을 발판으로 역사적 상상력을 발휘해 해석한다. 이것이 채널의 중요한 무기다
- [제안] 상상의 절차(다섯 단계):
  1. **기록 고정**: 원문 한 줄을 그대로 적는다(원문 대조). 여기서 바꾸지 않는다
  2. **조건 재구성**: 기록 밖의 확인 가능한 조건을 모은다 — 지형·계절·거리, 주변 정세(중국 사서), 앞뒤 기록, 고고학 자료, 같은 시대의 비슷한 전례
  3. **가능한 해석 2~3개**: 그 조건에서 나올 수 있는 판단을 여러 개 세운다. 상대의 합리성(5번)도 같이 세운다
  4. **가장 그럴듯한 하나 + 근거**: 왜 그 해석을 고르는지 한두 문장. 다른 해석은 설명란 또는 한 문장으로 남긴다
  5. **표시**: 내레이션에서 경계를 말한다. 예: "기록은 여기까지입니다. 여기서부터는 그날의 조건으로 재구성한 이야기입니다." 화면에서도 개념도 표기나 재현 컷의 톤으로 구분한다
- 상상의 선: 상상은 **조건과 동기**를 채운다. 기록에 없는 사건·실존 인물의 발언·숫자를 사실처럼 만들지 않는다. 가상 인물(예: 1부의 무명 노장)은 [연출]로 밝힌다. 복식·지형·계절 고증 규칙은 그대로 지킨다
- **마스터 태그 표(10/23)** — 모든 history-* 스킬이 이 표를 원본으로 쓴다. 각 스킬은 '쓰는 태그'만 고른다. 대본 표의 태그 열에 쓴다

| 태그 | 뜻 | 주로 쓰는 곳 |
|---|---|---|
| [기록] | 사료에 그렇게 적힘(사실 여부와 별개) | 전체 |
| [기록·대조] | 원문을 직접 대조함 | 롱폼 |
| [통설] | 학계 다수 해석 | 전체 |
| [추정] | 학계가 추정으로만 제시 | 쇼츠·건축 |
| [여러 설] | 학계 의견이 갈림 | 전체 |
| [미상] | 알 수 없음 | 쇼츠 |
| [해석] | 사료에 없는 의미 부여(제작자 해석) | 전체 |
| [상상] | 5-1 절차로 조건을 재구성한 판단 | 롱폼·쇼츠 |
| [연출] | 가상 인물·대사·색 등 화면 연출 | 전체 |
| [발굴] | 발굴 보고로 확인 | 건축 |
| [복원추정] | 복원 그림·경계의 추정 부분 | 건축 |
- 상상으로 세운 판단도 편의 '결정'이 될 수 있다(8번 편 수 기준). 단, 그 결정의 출발점이 되는 기록 한 줄은 반드시 있어야 한다

## 6. 기획 점검표 (주제를 잡을 때마다)
1. 이 편의 결정은 무엇인가? 한 문장으로 쓸 수 있는가
2. 그 결정에 진짜 대안이 있었는가(뻔한 선택이면 주제가 약하다)
3. 판단 근거(지형, 병력, 거리, 시간, 상대의 약점)를 **말로 설명할 수 있고**, 지도나 화면으로도 보여 줄 수 있는가
4. 기록·해석·상상을 구분할 수 있는가. 출발점이 되는 기록 한 줄이 있고 원문을 확인했는가. 상상은 5-1 절차를 거쳤는가
5. 제목이 질문인가
6. 끝에 다음 편으로 이어지는 조건이나 한계가 한 줄 있는가
7. 대본이 라디오 시험을 통과하는가(3번)
8. 영상미로 보여 줄 장면이 있는가. 어느 대목을 영상미 구간으로 둘 것인가(4번). 콜드 오픈에 쓸 클라이맥스 컷이 있는가(2번)
9. 상대의 판단이 그럴 만하게 그려져 있는가. 승리가 상대의 실수가 아니라 역이용으로 설명되는가(5번)
10. 세 겹 질문(세계 · 나라 · 전장)이 다 있는가. 세계 겹이 1~2분 안에 끝나는가. 전장 겹의 "왜?"에 세 가지 답(노림 · 상대가 걸린 이유 · 남긴 것)이 있는가(2-1)
11. 지도 세 단계(전략도 · 작전도 · 전술도)가 각 겹과 짝지어져 있는가(7-1). 지도의 영역이 그 시점 기록과 맞는가
12. 이 주제는 몇 편인가 — 세울 수 있는 결정의 수와 같은가(8번)
13. 판단 분석 구간(2-2)의 5칸을 채울 근거가 있는가. 사용자가 초고를 쓰고 판정 한 문장을 냈는가
14. 도트 그림이 한 곳 이상 들어가는가. 놓인 자리가 들판·길·물 위인가(7-3)
- 사용자가 겪은 것: 뻔한 주제(유리 승계)는 조회가 절반이었다 → 예상 밖의 각도를 찾는다

## 7. 화면·대본 원칙
- [확정] 내레이션은 설명하듯 자연스럽게 이어지는 '합니다'체(history-longform D-1)
- [확정 10/7] 지도를 보면 더 풍성하고 상상력 있게 이해되지만, 못 보는 사람도 이해할 수 있어야 한다
- [제안] 컷마다 하는 일이 있어야 한다: 판단의 근거를 보여 주거나, 판단의 무게를 느끼게 하거나. 둘 다 아닌 컷은 뺀다
- [제안] 기록과 해석을 말이나 설명란에서 구분해 밝힌다. 해설 채널의 신뢰는 여기서 나온다
- 시네마틱의 뜻: 영화 같은 화면과 음악으로 해설을 전달하고 전투의 무게를 느끼게 한다는 것. 긴 대화와 연기로 끌고 가는 드라마를 만든다는 뜻은 아니다(AI 영상이 약한 부분)
- [확정 10/12] **세력 색을 모든 전투 컷에서 지킨다**: 고구려 붉은 옷·붉은 깃발 / 부여 흰 옷·짙은 모피. 돌격 컷은 진행 방향 앞에 적의 색만, 뒤에 아군의 색만 둔다(색이 섞이면 아군을 치는 것처럼 보인다)
- [확정 10/12] **고증이 몰입을 지킨다**: 지형·계절이 만드는 물리(진창 깊이 등)와 규모(진영 크기)가 어긋나면 시청자 몰입이 깨진다. 기록이 정도를 말하지 않으면 '그 상황에서 상대가 진군을 택할 만한 수준'으로 그린다

### 7-1. 전략·전술 지도 체계 [확정 10/10, 색·국경 v3 확정 10/12 — 사용자가 준 지도 레퍼런스 기준]
- 레퍼런스에서 가져올 원리(Min Maps Asia 영상 스틸에서 읽은 것):
  - **바탕**: 지형 음영(돋을새김), 바다, 강. 바탕은 차분하고 세력 색이 주인공이다
  - **세력 = 단색 면**: 나라마다 색 하나. 아래 지형이 비친다
  - **국명 라벨**: 큰 글자로 영역 위에 깔거나, 검은 띠 위 흰 글자
  - **방어선·요새선 = 캡슐 띠**: 검은 테두리 + 세력 색으로 채운 둥근 띠. 산맥·강을 따라 놓아 '이 선을 지킨다'를 한눈에 보인다
  - **군대·수군 = 사각 토큰**: 테두리 있는 사각 안에 병종 그림
  - **거점 = 흰 사각 점**, **교역·해상로 = 남색 점선**
  - **줌**: 넓은 동아시아 전도 → 특정 지역 확대. 같은 바탕에서 줌인해 맥락에서 세부로 들어간다
- 우리 채널에 맞춘 규칙:
  - [제안] 세 단계 줌: **전략도**(동아시아·주변 강국, 세계 겹) → **작전도**(진군로·거리·계절, 나라 겹) → **전술도**(전장 개념도, 전장 겹)
  - [제안] 라벨은 한글을 주로, 필요할 때 한자 병기. 지명·거점 표지는 붉은 인장 이름표('§') 또는 붉은 원 표지(쇼츠 markers). **선택지·작전 설명과 판단 분석에는 인장·상자를 쓰지 않는다**(longform E-6·E-7, 10/17)
  - [확정 10/12, 지도 v3] **국경은 지형을 따른다**: 산줄기(분수령)·큰 강을 경계로 자연스럽게 맞물린다. 직선·다각형 국경 금지. 세력 면은 **진하고 채도를 눌러** 나라마다 확실히 다른 색, 아래 지형 음영이 비친다
  - [확정 10/12] 세력 색(지도 v3 → 바탕은 v4-S, 원장 C1·C4): 고구려 = 짙은 적갈 (96,34,29) / 부여 = 짙은 남회 (42,58,86) / 신(新) = 짙은 올리브 (70,74,22) / 낙랑 = 먹회색 (84,88,102)(11/04 원장 C4 — 당과 구분이 약한 편만 올리브 예외로 원장에 기록) / 흉노·선비·옥저·삼한은 history-longform 지도 키트의 표. 백제 = **황금색 계열**(10/21~22, 옛 기록의 금칠 근거 — 청색에서 변경. RGB는 BC 1세기 프리셋 제작 때 정함, production-standards 2절). 신라·가야는 처음 나오는 편에서 정하고 시리즈 안에서 바꾸지 않는다(10/10의 '부여 = 회백·흑', '중원 = 남청' 안은 v3로 대체)
  - [확정 10/12] 영역은 그 시점의 기록으로 그린다: 1세기 초 고구려는 동해에 닿지 않는다(옥저가 사이에, 동옥저 복속은 56년). 영역 근거는 대본 표에 적는다
  - [확정 10/12] 전략도의 보조 라벨은 그 편의 판단에 필요한 것만(2부: 선비·오환 / 낙랑 / 삼한)
  - [확정 10/12] 쇼츠도 롱폼과 같은 지도를 쓴다 — 현행 v4-S(세로 판·전체 화면은 history-map-v4 10절 mapvid, 원장 C1 11/04). 이전 AI 재채색 한반도 지도는 도시 위치·이동 경로만 보일 때의 대체용
  - 모든 라벨·표지는 내레이션에도 나온다(3번). 지도 표기는 [개념도]와 [기록에 근거한 위치]를 구분하고, 위치 이견이 있으면 화면 주석 또는 설명란에 적는다
  - 렌더러 구현은 history-longform(layers: tint · arrow · sprite · tag · dot · token · label · dash · band, 지도 키트 bake3)
- 하지 않는 것: 레퍼런스 영상의 지도 화면·아이콘을 그대로 복제하지 않는다. 문법(면 · 띠 · 토큰 · 점선 · 줌)만 가져온다

### 7-2. 시그니처 오프닝 [확정 10/12]
- 채널 고정 영상미: **수묵화 → 화면에 번지는 먹물 → 같은 구도의 실사 인물이 움직임**(약 10초). 이 채널이 수묵화로 시작했다는 정체성을 매 편 첫머리에 새긴다
- 매 편 그림(인물·장소)만 바꾸고 틀은 같다. 콜드 오픈의 '되감기'도 같은 먹 번짐으로 한다(2번 첫 화면 순서)
- [확정 10/12] **쇼츠는 3초 축약판**: 45초 신작의 첫 장면을 수묵 스틸 → 먹 번짐 → 같은 구도의 실사 움직이는 컷으로(제목·첫 내레이션은 0초부터). 구현은 history-shorts D-1·F-5
- 구현·에셋은 history-longform E-4
- **[확정 10/25] 오프닝 = 줄거리 요약 훅(롱폼·쇼츠 공통, 배경지식 0·초등학생 기준)** — 질문만 먼저 던지면 원인을 모르는 시청자는 '어쩌라고?'가 된다(온조 편 v1.4, 배경지식 없는 시청자 피드백). 질문 앞에 줄거리를 먼저 들려준다
  - 4단: ① 아는 이름으로 주인공 소개(예: "고구려를 세운 영웅, 주몽. 그의 세 아들 가운데 막내, 온조.") ② 무엇을 잃고 어디로 가나 ③ 결말까지 한 문장 + 궁금증 한 구절(예: "…자기를 받아 준 이웃 나라까지 삼키고 한강의 1인자가 됩니다.") ④ 과정을 묻는 '어떻게' 질문 하나(예: "힘없는 왕자는 어떻게, 한강의 주인이 됐을까요.")
  - 공통 규칙: 고유명사는 이미 아는 이름 위주로 적게, 이 편에서 처음 나오는 나라·인물 이름은 풀어 쓴다('이웃 나라'). 어려운 한자어 금지. 대사로 시작하지 않는다. 결말 문장의 화면은 기록에 있는 사건 컷만. '어떻게' 질문은 직전 짧은 무음 + 큰 자막(핵심어 금색) + 이 문장만 따로 녹음
  - **롱폼**: 내레이션 약 15초 + 시그니처 3초 + 제목 ≈ 18~20초. 상세·실패 사례는 history-longform E-4
  - **쇼츠(신작·재편집 공통)**: 더 짧게 — 약 6~8초. 2문장으로 줄인다: 첫 문장(0초부터, 약 4~5초) = ①+②+③을 한 문장으로(아는 이름 + 약자 + 결말), 둘째 문장(약 3초) = 0.3초 무음 뒤 '어떻게' 질문(롱폼과 같은 문장이면 그 녹음을 재사용). 첫 적용(10/25 온조 재편집 공통 앞머리, 약 7.5초): "주몽의 막내아들, 밀려난 왕자 온조는, 자기를 받아 준 이웃 나라까지 삼킵니다." → "힘없는 왕자는 어떻게, 한강의 주인이 됐을까요." 시그니처 3초는 첫 문장 아래에 깔고, 제목은 0.15초부터(history-shorts D-1 그대로). 재편집 쇼츠(M)는 이 2문장 앞머리를 붙이고 그 뒤에 각 편의 롱폼 구간을 잇는다(화면은 롱폼 컷 9:16 크롭 재사용 — 화질은 시안으로 확인)
  - 검수: 대본 관문에서 배경지식 0 시청자 기준으로 "누가, 무엇을 잃고, 무엇이 되나"를 오프닝만 듣고 한 줄로 말할 수 있는지 본다

### 7-3. 도트 그림 [확정 10/17]
- **매 편 한 곳 이상** 넣는다. 롱폼·쇼츠(재편집·신작)·건축 시리즈 모두 해당. **[10/23] 금지 구간: 죽음·비극 장면, 판단 분석 구간**(톤을 깨지 않게)(10/4의 '선택 사항, 기본은 넣지 않음' 규칙은 10/17 결정으로 폐기 — 10/23 재확인)
- 성격: **깨알 등장**. 지도나 그림 위를 작게 지나가는 장식(기마병 무리, 행군 대열, 배, 불꽃, 연기 등). 축척과 무관하고, 내레이션에서 언급하지 않는다(라디오 기준 예외 — 정보가 아니라 장식)
