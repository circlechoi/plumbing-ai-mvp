# 시각 검수 게이트 (style.json rules.visual_review_gate)
사용자에게 보이기 전, 장면별 대표 프레임(전체 해상도)을 만든 사람이 아닌 검수자가 채점한다. 합격 8/10.

## 필수 불합격 (점수와 무관)
1. 한자 노출 (지명 병기, 깃발, 원문 카드 포함)
2. 세력 영역: 영역 안 칠해지지 않은 육지, 해안선과 어긋난 경계
3. 라벨·말풍선·아이콘이 서로 또는 핵심 요소와 겹침, 화면 밖 잘림
4. 장면 핵심이 그림만으로 안 읽힘 (예: 토산이 성벽보다 높음, 붕괴, 함락 ✕)
5. 이전 사용자 지적 재발 (편별 피드백 목록과 대조)

## 채점 항목
- 폰 화면 가독성 / 구도(빈 곳·겹침·잘림) / 장면 간 그림체 일관성 / 내레이션 전달력

## 절차
1. 장면마다 대표 프레임 2~3장 저장(전체 해상도)
2. 검수자에게 대본 요약 + 필수 불합격 항목 전달, 장면별 점수·수정안 받기
3. 수정 → 불합격 장면만 재검수 → 전 장면 8점 이상이면 사용자에게
